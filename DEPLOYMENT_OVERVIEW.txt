🚀 QUICK START (5 MINUTES)
═══════════════════════════════════════════════════════════════════════════

1. Setup Environment (First Time Only)
   ─────────────────────────────────────
   $ ./scripts/setup-deployment.sh
   
   This checks:
   • Required tools (git, node, npm, gcloud, koyeb)
   • Cloud account credentials
   • SSH access to Oracle instance
   • Creates deployment configuration

2. Deploy to All Platforms
   ──────────────────────────
   $ ./scripts/deploy-all.sh --all
   
   This:
   • Commits code to git
   • Deploys to Google Cloud Run
   • Deploys to Oracle Cloud
   • Deploys to Koyeb
   • Shows all three URLs
   • Estimated time: 5-10 minutes

3. Verify Deployment
   ───────────────────
   $ ./scripts/check-health.sh full
   
   This:
   • Checks health of all servers
   • Verifies live data is accessible
   • Shows summary report

4. Update Configuration
   ────────────────────
   Edit public/config.js with the URLs from deployment:
   
   servers: {
       primary: 'https://your-gcp-url.run.app',
       fallback: 'http://138.2.91.18:3000',
       backup: 'https://your-koyeb-url.koyeb.app'
   }

   Features:
   ✓ Global distribution
   ✓ Automatic scaling
   ✓ Integrated logging
   ✓ Health checks built-in

2. ORACLE CLOUD (Fallback)
   ────────────────────────
   Type:        Compute Instance (Always Free)
   Cost:        FREE (Always Free tier)
   Uptime:      Manual management
   Cold Start:  None (always warm)
   Startup:     ~2-3 minutes
   
   Features:
   ✓ 6GB RAM included
   ✓ 24/7 operation
   ✓ PM2 process management
   ✓ Clustering support

3. KOYEB (Backup)
   ───────────────
   Type:        Serverless (Auto-scaling)
